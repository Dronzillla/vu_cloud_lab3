Task 2 Requirements

  • Show 4-5 requests WITH POST
  • Show 4-5 requests with GET +redirect
  • 2-4 queris with Handle cookies (pelase do not forget to make cookie jar anonymous, f.x., some part can be made with xxxxx or *****)

Solution

  • I created a small Flask MVC application primarily to test cURL with POST, GET+redirect, and cookies.
  • The app provides full CRUD for Tasks using both API endpoints and HTML forms.
  • Each task has validated fields: title, description, due date, and completion status.
  • Validation checks: title + due date cannot be empty, title must include letters, due date cannot be in the past.
  • Uses SQLAlchemy with a Postgres database hosted on Railway; app is also deployed on Railway.
  • API routes are used for cURL testing: multiple POST requests, GET with redirects, and 2–4 cookie-handling examples.
  • Frontend uses Jinja2 templates without additional libraries.
